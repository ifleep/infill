# INFiLLPK — WordPress theme

This repo is a custom WordPress theme (`wp-content/themes/infillpk/`) for WooCommerce +
Elementor, deployed on Hostinger. See `README.md`.

An earlier Next.js prototype is archived at `archive/nextjs-prototype/` — useful as a design/asset
reference (see its README), but it is not the production codebase. Don't extend it further; new
work goes into the WordPress theme.
